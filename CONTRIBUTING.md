# Contributing

Thanks for helping improve this CapSolver integration demo.

1. Open an issue before proposing a large change.
2. Keep CapSolver behavior in [`capsolver-agent`](https://github.com/capsolver-ai/capsolver-agent); this repository should contain examples only.
3. Add or update a runnable file under `examples/`.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
5. Never commit API keys, cookies, tokens, proxy credentials, or target-site account data.

Examples must be limited to lawful, user-authorized, terms-compliant automation.
